# Парсер вакансий с hh.ru для PostgreSQL

Проект позволяет собирать данные о компаниях и вакансиях с сайта hh.ru, сохранять их в базу данных PostgreSQL 
и анализировать через удобный интерфейс.

## Возможности
- Получение данных о компаниях и вакансиях через API hh.ru
- Автоматическое создание базы данных и таблиц
- Заполнение БД данными
- Поиск вакансий по ключевым словам
- Анализ зарплат (средняя, вакансии с зарплатой выше средней)
- Вывод статистики по компаниям

## Технологии
- Python 3.8+
- PostgreSQL 14+
- Библиотеки: `psycopg2-binary`, `requests`

## Установка и настройка
1. Клонировать репозиторий:
```bash
git clone https://github.com/ваш-username/название-репозитория.git cd название-репозитория
```

2. Установить зависимости:
```bash
pip install -r requirements.txt
```

3. Настроить подключение к PostgreSQL:
- Создать файл `config.py` в корне проекта:
```python
DB_CONFIG = {
    'user': 'ваш_пользователь_postgres',
    'password': 'ваш_пароль',
    'host': 'localhost',
    'port': '5432'
}
```
- Убедитесь, что пароль содержит только ASCII-символы

## Запуск проекта
1. Запустите главный скрипт:
```bash
python main.py
```
2. Выберите действие через интерактивное меню:
```
1. Список компаний и количество вакансий
2. Все вакансии
3. Средняя зарплата
4. Вакансии с зарплатой выше средней
5. Поиск вакансий
0. Выход
```

## Примеры использования

## Устранение неполадок
При ошибках кодировки:
- Убедитесь, что все файлы сохранены в UTF-8
- Проверьте отсутствие спецсимволов в пароле PostgreSQL
- Добавьте параметр `client_encoding='utf-8'` в подключении

При проблемах с подключением к БД:
- Проверьте правильность данных в `config.py`
- Убедитесь, что PostgreSQL запущен и доступен
